Why won't my .jxl file open?

JPEG XL is a new image format. Most browsers, phones and apps haven't enabled it yet, so a downloaded .jxl often won't open — even though it's a perfectly valid image. This viewer decodes it locally so you can see it right away, and lets you save a universal copy as JPG or PNG. Need the file in another format permanently? Use the JXL to JPG converter or JXL to PNG converter.

What this viewer opens

The viewer decodes JPEG XL (.jxl) files the way a browser would if it supported the format natively, so you see the real image rather than a preview or a thumbnail. It also opens the everyday formats — JPG, PNG, WebP and GIF — which is handy when you have a folder of mixed files and just want to check what is inside them without launching an editor.

Everything is decoded by your own device. There is no upload, no queue and no temporary copy sitting on someone's server, which is why the viewer works exactly the same on a locked-down work laptop as it does at home.

FAQ

How do I open a .jxl file?
Drop it onto this page (or click to select). It opens instantly in your browser — nothing is uploaded.
Does the viewer change my file?
No. It decodes a copy in memory to display it. The original .jxl on your disk is left exactly as it was.
Is there a file size limit?
There is no limit imposed by the site. Very large images are limited only by the memory your browser has available, and full-resolution phone photos are handled comfortably.
Why does my phone show a grey box instead of the photo?
That usually means the operating system, not this page, is refusing the format. Opening it here bypasses that, because the decoding happens in the browser tab.
Can I use it offline?
Once the page has loaded, decoding runs locally, so a brief connection drop won't interrupt viewing a file you've already opened.
Is it private?
Yes. The file is decoded locally in your browser and never leaves your device.
Can I save it as JPG or PNG?
Yes — after it opens, download it as JPG or PNG with one click.
