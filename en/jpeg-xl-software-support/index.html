Which Apps Support JPEG XL?

Support has grown steadily since the format was standardised, but it is uneven in ways that surprise people: your phone may open a .jxl that your desktop can't. Here's the state of play, without the cheerleading.

Operating systems

Apple is the outlier, in a good way. macOS and iOS have handled JPEG XL natively since 2023 — Preview, Quick Look, Photos and Finder thumbnails all work with no extra software. If you're on a Mac, the format effectively already won.

Windows does not open .jxl out of the box. A JPEG XL extension has been available through the Microsoft Store, and various third-party codec packs add support to Explorer and Photos, but none of it is installed by default. Most Windows users meet the format as an error message.

Linux depends on your desktop. GNOME and KDE image viewers have gained support through their imaging libraries, and anything built on ImageMagick, libvips or GdkPixbuf with the right plugin will handle it. On a current distribution it usually works; on an older one it usually doesn't.

Photo editors and professional tools

🎨

Adobe

Camera Raw reads JPEG XL, and Adobe's modern DNG raw files use JPEG XL compression internally — the format is already inside the Adobe pipeline. Direct open and export in Photoshop has historically needed a plugin rather than being built in.

🖼️

Affinity Photo

Has offered JPEG XL import and export, which made it an early favourite among photographers who wanted to use the format seriously without waiting for Adobe.

🐧

GIMP

Supports JPEG XL import and export in current versions through libjxl. If yours doesn't, you're on an older build — this is one of the cases where updating actually fixes it.

📷

darktable and RawTherapee

The open-source raw workflow has picked up JPEG XL export, which matters for photographers who want an archival master that isn't a 100 MB TIFF.

🔍

XnView MP and IrfanView

The two viewers most Windows users end up installing. Both read JPEG XL, both batch-convert, and both are free for personal use. If you handle .jxl files regularly on Windows, start here.

⚙️

ImageMagick and libvips

Both handle JPEG XL when built with the delegate, which most current packages are. For scripted or server-side processing this is where the real work gets done.

The reference tools

Underneath nearly everything above sits libjxl, the open-source reference implementation, and its two command-line tools: cjxl to encode and djxl to decode. They are the most complete and up-to-date implementations that exist, and they're free.

For anyone processing images in bulk they're also simply the right tool — a GUI is a poor way to convert forty thousand files. cjxl photo.jpg photo.jxl losslessly re-packs an existing JPEG, and djxl reverses it exactly.

What this means in practice

If you just received one file

Install nothing. Open it here or convert it to JPG and get on with your day. Installing a codec to look at one photo is a poor trade.

If you're on Windows and see them regularly

Install XnView MP or IrfanView. Both open .jxl, both batch-convert, and both are lighter than adding system-wide codecs you'll forget you installed.

If you're on a Mac

You already have everything. Double-click the file. This is the one place where JPEG XL behaves like a normal format.

If you're publishing images on the web

Don't use JPEG XL as the only format — most of your visitors are on Chrome and will see nothing. Serve AVIF or WebP with a JPEG fallback, and read the AVIF comparison before choosing.

FAQ

Why doesn't Windows Photos open .jxl?
Because Microsoft has never shipped the codec by default. Windows handles image formats through installable codec packages, and the JPEG XL one isn't part of a standard installation. It's an omission rather than a technical barrier.
Is there a plugin to open .jxl in Photoshop?
Community plugins built on libjxl exist and are the usual route. Adobe's own support arrived first through Camera Raw and DNG rather than as a direct Photoshop file format, so check Camera Raw before hunting for a plugin.
Will Chrome ever add it back?
Nobody outside Google knows. Support was removed in 2023 for lack of ecosystem interest; since then Apple shipped native support and a memory-safe implementation has been in progress, both of which weaken the original reasoning. The full story is here.
What's the safest format to send someone?
JPEG, still, and it isn't close. Every device made in the last thirty years opens it. Use JPEG XL for what you keep and JPEG for what you send.
Can Android open .jxl files?
Not reliably. Support depends on the manufacturer's image stack rather than on Android itself, so two phones on the same Android version can behave differently. The browser viewer works on any of them.
Do I need to install anything to use this site?
No. The encoder and decoder are compiled to WebAssembly and load with the page, which is why it works in Chrome even though Chrome itself can't display JPEG XL. Your files stay on your device throughout.
