How to Open a HEIC File on Windows

Windows will happily point you at a paid Store listing to view a photo your nephew sent you. You don't have to buy anything. Here are four ways round it, easiest first.

Why Windows is asking for money

A .heic photo is compressed with HEVC, the same technology behind 4K video — and HEVC is covered by patents that carry licensing fees. Microsoft passed that cost on: for years, viewing these files required the «HEVC Video Extensions» from the Microsoft Store, priced at around a euro.

There is a free version of that extension published «from Device Manufacturer», but Microsoft does not surface it in search results, and whether you're entitled to it depends on your PC. Rather than hunt for it, it's usually quicker to sidestep the codec altogether.

Four ways to open it

1. Convert it to JPG

Drop the file into the converter on this page. You get a normal .jpg that opens in Photos, in email and on any website — and the conversion happens inside your browser, so the photo never leaves your PC.

2. Just view it

If you only need to look at the picture once, use the viewer. It decodes the HEIC on the spot without producing a new file.

3. Install a viewer that bundles its own decoder

IrfanView with its plugin pack, XnView MP, or GIMP will all open HEIC without Microsoft's extension. Worth it if you deal with these files constantly.

4. Buy the extension

If you'd rather Windows Photos handled them natively, «HEVC Video Extensions» in the Microsoft Store does exactly that. It's the only option here that costs money.

For most people the first option ends the problem for good: once the photo is a JPG, nothing on any device will ever question it again.

Stop the problem at the source

If the photos keep coming from the same iPhone, it's worth changing the setting on that phone instead of converting for ever. On the iPhone: Settings → Camera → Formats → «Most Compatible». From that moment the camera saves JPEG instead of HEIC.

There's a second setting that catches people out. Under Settings → Photos, scrolling to the bottom, «Transfer to Mac or PC» should be set to «Automatic» — that converts photos to JPEG as they're copied off the phone. If it's set to «Keep Originals», you get raw HEIC files on your PC no matter what.

Windows 10 or Windows 11?

It matters. Windows 11 handles HEIC far more often out of the box — many machines display these photos in the Photos app with no extra steps, though some still prompt for an extension depending on how the PC was configured by its manufacturer.

Windows 10 is where people get stuck. There, a .heic will usually produce either a blank preview, a «This file can't be opened» message, or a redirect to the paid Store listing. If you're on Windows 10, skip straight to converting.

What doesn't work (and why people try it)

The most common attempt is renaming the file: change photo.heic to photo.jpg and hope Windows plays along. It doesn't work, and it's worth understanding why, because with some other file types it does.

Renaming only works when the contents were already the format you're claiming — that's the case with a .jpg-large from Twitter, which is a JPEG wearing the wrong label. A HEIC is genuinely a different format inside: the data is compressed with HEVC, and calling it .jpg doesn't teach Windows how to decode it. All you get is a JPG that won't open either, plus a file whose name now lies about its contents.

Two other dead ends worth naming. Emailing the photo to yourself doesn't convert it — most mail clients pass the file through untouched. And opening it in Paint or Windows Photos and hoping for a «Save as» option fails at the first step, because those apps can't read the file to begin with.

Common questions

Can I just rename a .heic to .jpg?
No. Unlike a .jpg-large, a HEIC really is a different format inside. Renaming produces a file that still won't open and now has a misleading name.
Do I have to pay to open HEIC on Windows?
No. Converting the file to JPG costs nothing and solves it permanently. The paid extension is only worth it if you want Windows Photos to open HEIC directly.
Is there a free HEVC extension?
There is one published «from Device Manufacturer» in the Microsoft Store, but Microsoft hides it from search and availability depends on your PC. Converting is more reliable.
Is it safe to convert my photos on a website?
On this site the conversion runs inside your browser with WebAssembly — the file is never uploaded. Not every converter works that way, so it's worth checking before using one.
Will converting reduce the quality?
Slightly, because JPEG is an older lossy format. For viewing and sharing you won't see the difference. Keep the HEIC original if you're archiving.
Can I convert a whole folder at once?
Yes. Select as many .heic files as you like and they're converted in one batch, all locally.
Why does Windows 11 open them but Windows 10 doesn't?
Windows 11 ships with broader HEIF support on most machines. Windows 10 generally requires the extension that Microsoft charges for.
